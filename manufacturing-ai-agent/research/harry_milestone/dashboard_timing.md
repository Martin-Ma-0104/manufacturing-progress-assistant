# Manual dashboard and agent timing protocol

Status: not measured. Do not use API timings as human task times.

Use the same synthetic dataset, dates, machine filter and units. Show a clearly labelled synthetic session rather than repointing the production service. Give an unscored practice task first. For each question, start when it is shown and stop when the participant submits an answer. Score correctness against the frozen manual oracle, log actions and failures, and include clarification time. Alternate dashboard-first and agent-first order across repeated tasks/participants. Record learning effects and the very small sample as limitations. No superiority or causal speedup claim follows from a single developer trial.
